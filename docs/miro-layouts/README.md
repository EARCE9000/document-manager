# Miro の並べ方のモデル

Miro 連携([../miro.md](../miro.md))で、プロジェクトの枠の中に資料をどう並べるかの案を、draw.io の図にまとめたものです。
どれも案の段階で、いまの実装(フォルダの見出しごとに並べる)をこの形に変えたわけではありません。

各図の右側に、そのモデルの決まりごと(振り分け・並び順・伸び方)を書いています。

| ファイル | モデル | 並べ方 | 向いているもの |
|---|---|---|---|
| [quadrant-cross.drawio](quadrant-cross.drawio) | 十字型(4 区画) | 左上 要件定義〜設計、左下 テスト〜リリース(V 字で向かい合わせ)、右上 管理系、右下 ミーティング(週 × 曜日) | 工程のはっきりした開発プロジェクト |
| [folder-columns.drawio](folder-columns.drawio) | フォルダ列型 | 一番上のフォルダごとに 1 列、下の階層は ▼ の小見出し | フォルダ分けがそのまま工程や種類になっているもの |
| [timeline.drawio](timeline.drawio) | 時系列型 | 1 か月 = 1 行(上が古い)、月の中は日付順に左から右へ(7 枚で折り返す) | フォルダやタグが整っていないもの、経緯を追いたいとき |
| [split-shelves.drawio](split-shelves.drawio) | 左右分割・棚型 | 左半分 管理系、右半分 段階ごとの棚(準備 → 実施 → 実施後) | イベント・リリース作業・移行など、当日を中心に回る案件 |

十字型・時系列型・棚型の振り分けや色分けは、資料のタグ(`区分:` `工程:` `会議:` `段階:`)で決める前提です。タグがまだ無い資料でも並ぶようにしてあります(十字型と棚型は「未分類」の段、時系列型は灰色)。
